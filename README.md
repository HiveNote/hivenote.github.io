## 반복해서 듣는 암기루프
## 수험생을 위한 요약 노트 반복 학습  
## 요약노트 / 오답노트

# 주요기능
주입식 학습은 반복입니다.
오답노트/요약노트를 정리하고 듣고, 테스트를 통해 암기 상황을 점검할 수 있습니다.
기록한 메모를 주제별로 들을 수 있는 메모장 입니다.  
다른 개인정보를 요구 하지 않습니다.  
모든 메모 화면에서 제스처를 인식합니다.  

# 메모장의 내용을 파일로 내보내거나, 파일에서 가져 올 수도 있습니다.  
이전에 다른 곳에서 관리하는 메모들을 가져오세요.  

# 시험 준비 중이시라면, Pick 기능을 사용해 보세요.  
메모장들 중에서 신호등(빨/노/녹)에 따라 표시 빈도가 정해 집니다.  
암기 해야 할 항목들을 더 자주 표시합니다.  
Pick 기능 상단의 내용 숨기기를 사용해서, 제목만 보고 내용을 생각해 보세요. (자율 학습)  
내용을 숨기고 진행 할 수 있어요. 화면을 클릭하면 내용을 보실 수 있습니다.  

# 찾기 기능을 사용해 보세요.  
전체 데이터에서 단어나 문장을 검색 할 수 있습니다.  

# 공유 기능을 사용해 보세요.  
텍스트나 그림 카드로 메모 내용을 공유 할 수 있습니다.  

# 위젯을 활용해 보세요.  
배경 화면에서 Pick 과 동일한 설정으로 학습을 할 수 있습니다.  

# 독서 노트나 메모장의 전체 듣기, 섞어 듣기를 이용해 보세요.  
화면상의 특정 위치에서 전체 내용을 순서대로 또는 임의로 들을 수 있어요.  
이동 중에도 들으면서 암기해 보세요.
잘들기 전에 요약노트 전체 듣기를 해 보세요.  
색상별/즐겨찾기로 구분해서 듣기 가능합니다.
