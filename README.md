# 암기루프

https://play.google.com/store/apps/details?id=com.olivearchi.goodroutine

## 반복해서 듣는 암기루프
## 수험생을 위한 요약 노트 반복 학습  
## 요약노트 / 오답노트

# 주요기능
주입식 학습은 역시 반복입니다.
오답노트/요약노트 정리하고 듣고, 테스트 통해 암기 진도 점검하는 앱입니다.  
메모를 주제별로 들을 수 있는 메모장 입니다.  
개인 정보 보호(개인정보를 필요로 하지 않습니다.)  
사용 편의성 (모든 메모 화면 제스처 인식)  

# 메모장 내용을 파일로 내보내거나, 파일에서 가져오기
요약 노트를 하나로 관리하세요.

# 시험 준비 중이라면, Pick (학습 진도 테스트)
메모장들 중에서 신호등(빨/노/녹)에 따라 Pick 노출 빈도가 정해 집니다.  
붉은색 항목들이 더 자주 표시합니다.  
Pick 기능 상단의 내용 숨기기를 사용해서, 제목만 보고 내용을 생각해 보세요. (자율 학습)  
내용을 숨기고 진행 할 수 있어요. 화면을 클릭하면 내용을 보실 수 있습니다.  

# 찾기 기능을 사용해 보세요.  
전체 데이터에서 단어나 문장을 검색 할 수 있습니다.  

# 공유 기능을 사용해 보세요.  
텍스트나 그림 카드로 메모 내용을 공유 할 수 있습니다.  

# 위젯을 활용해 보세요.  
배경 화면에서 Pick 과 동일한 설정으로 학습을 할 수 있습니다.  

# 듣기 학습 시간 통계  
- Bigneer : 평균 ~200점  
- Challenger : 평균 200 ~  
- Conqueror : 평균 500 ~  
- Winner : 평균 1000 ~  

# 독서 노트나 메모장의 전체 듣기, 섞어 듣기를 이용해 보세요.  
전체 내용을 순서대로 또는 임의로 들을 수 있어요.  
짜투리 시간이나 이동 중에 들으면서 암기해 보세요.  
잘들기 전에 요약 노트 전체 듣기는 쾌적한 수면 보장     
색상별/즐겨찾기 구분 듣기 가능  

# [계정 및 데이터 삭제 안내]  
본 앱은 별도의 자체 서버에 사용자 정보를 저장하지 않습니다.  
사용자가 구글 드라이브 백업 기능을 위해 연동한 구글 계정 정보 및 백업 데이터는 다음의 방법으로 직접 삭제하실 수 있습니다.  
i. 구글 계정 설정 -> 보안 -> 계정 액세스 권한이 있는 제3자 앱 -> 'GoodRoutine' 선택 후 [액세스 권한 삭제]  
ii. 구글 드라이브 -> 설정 -> 앱 관리 -> 'GoodRoutine' 선택 후 [숨겨진 앱 데이터 삭제]
